# Фаза 4 — Распределение вычислений и управление ресурсами

Цель: действительно выполнять задачи на разных компьютерах, динамически выбирая оптимальный узел.

## Статус: ⬜ не начато

## Зависимость

Эта фаза опирается на законченные Contracts (Фаза 1) и рабочий обмен Core↔Agent (Фазы 2–3). Без надёжного взаимодействия устройств планировщик не имеет смысла.

## Состав работ

| Подсистема | Задачи | Приоритет |
|---|---|---|
| **Представление задач** | Формат задачи, жизненный цикл (queued → running → done/failed), приоритеты, зависимости, отмена | P2 |
| **Очередь задач** | Буферизация, обработка приоритетов | P2 |
| **Планировщик** | Оценка стоимости задачи, выбор узла по возможностям/нагрузке/температуре/доступности | P2 |
| **Исполнение** | Доставка команды агенту, изоляция кода, ограничение ресурсов, результат | P2 |
| **Интеллектуальное управление** | Сравнение узлов, управление памятью и моделями (загрузка/выгрузка) | P2 |
| **Отказоустойчивость** | Повтор до 3 раз, перенос на другой узел, контроль температуры | P2 |
| **Дробление задач** | Разделение вычислений между несколькими узлами | P3 |

## Проверка

Целевой сценарий: подать задачу → Core выбирает узел → агент исполняет → Core возвращает результат.
