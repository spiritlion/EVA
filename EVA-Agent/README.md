# EVA-Agent

Программный представитель устройства в распределённой системе EVA.

EVA-Agent устанавливается на каждое подключаемое устройство и выступает посредником между EVA-Core и аппаратными возможностями устройства. Core не знает внутренних особенностей железа — он общается с ним через единый интерфейс агента.

## Возможности (реализовано)

- **Формирование запроса регистрации** по контракту `registration/request` (`eva_agent/client.py`).
- **Отправка регистрации на Core** по HTTP (`POST /api/v1/nodes/registration-requests`).
- Параметры подключения и идентификации через переменные окружения.

## Структура

```
EVA-Agent/
├── pyproject.toml
└── src/eva_agent/
    ├── main.py    # точка входа (python -m eva_agent.main)
    ├── config.py  # настройки (адрес Core, идентификация)
    └── client.py  # HTTP-клиент Core, сборка запроса регистрации
```

## Требования

- Python 3.13+
- Зависимость: `aiohttp` (см. `pyproject.toml`).

## Установка

```bash
# в каталоге EVA-Agent
python -m venv .venv
.venv/Scripts/pip install -e .
```

## Запуск

```bash
.venv/Scripts/python -m eva_agent.main
```

При запуске агент формирует запрос регистрации и отправляет его на Core. По умолчанию Core ожидается на `http://127.0.0.1:8080`.

Настройки через переменные окружения:

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `EVA_CORE_URL` | `http://127.0.0.1:8080` | Адрес EVA-Core |
| `EVA_AGENT_ID` | (пусто → генерируется) | Идентификатор агента (UUID) |
| `EVA_PLATFORM` | `windows` | Платформа устройства |
| `EVA_AGENT_VERSION` | `0.1.0` | Версия агента |

## Статус разработки

Реализованы: базовый каркас и отправка запроса регистрации. Ожидает реализации: сбор реальной телеметрии (CPU, память), авторизация, WebSocket-соединение, приём команд, heartbeat.
